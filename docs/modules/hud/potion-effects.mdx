# PotionEffects

Displays your currently active potion effects and their remaining time.

## Settings

- **Color** — The color of the effect names.
- **Animations** — Toggle animations for the list (e.g., sliding when effects expire).
- **ColorMode** (Enum): `Dynamic`, `Static`.
- **Sorting** (Enum): `Lexicographical`, `Alphabetical`.
- **Icons** — Toggle the display of potion effect icons.
- **Duration** (Category)
    - **Parentheses** — Enclose the remaining time in parentheses.
    - **Color** — The color of the duration text.
