# TPS

Displays the server's Ticks Per Second (TPS).

## Settings

- **Color** — The color of the TPS value.
- **Label** (Category)
    - **Color** — The color of the "TPS" label.
- **Colon** — Toggle the colon after the label.
- **Mode** (Enum) — Choose how to display TPS:
    - `Ticks`, `Tick Length`
- **Clamped** — Clamps the TPS value to a maximum of 20.0.
