# Armor

Displays the durability and status of your equipped armor.

## Settings

- **Scale** — *Size of this hud element.*
- **Durability** (Enum) — How to display armor durability:
    - `Off`, `Percentage`, `Whole`
- **Axis** (Enum): `X`, `Y`.
- **HotbarLock** (Category)
    - **AutoAdjust** — Automatically adjusts position to avoid overlapping with the hotbar.
