# FeatureList

A list of enabled modules.

## Settings

- **Color** — The color of the module names in the list.
- **Animations** — Toggle animations when enabling/disabling modules.
- **ColorMode** (Enum) — How colors are applied to the list:
    - `Dynamic`, `Static`
- **Sorting** (Enum) — How the list is ordered:
    - `Lexicographical`, `Alphabetical`
- **Case** (Enum) — Text casing for module names:
    - `Normal`, `Lower Case`, `Upper Case`
- **Metadata** (Enum) — How module settings/metadata are shown:
    - `Brackets`, `Normal`, `Off`
- **MetadataColor** — Customize the color of the metadata text.
