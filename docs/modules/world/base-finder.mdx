# BaseFinder

AFK module to find bases/stashes with minimal effort.

## Settings

- **Logger** (Category)
    - **Notification** (Sub-category):
        - **CensorCoords** — Hide coordinates in notifications.
- **Sound** — Play a sound when a base/stash is found.
- **Beds** — Detect beds.
- **EndPortals** — Detect end portals.
- **IgnoreDungeonChests** — Ignore chests found in dungeons.
- **Shulkers** — Detect shulker boxes.
- **Chests** — Detect standard chests.
- **EnderChests** — Detect ender chests.
- **Skulls** — Detect player/mob heads.
- **Spawners** — Detect mob spawners.
- **Hoppers** — Detect hoppers.
- **Dispensers** — Detect dispensers/droppers.
- **Donkeys** — Detect donkeys.
- **Llamas** — Detect llamas.
- **ChestRequired** — Only notify if a chest is present.

## Commands

- `basefinder`
- `basefinder <setting> [value]`
