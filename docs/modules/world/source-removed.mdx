# SourceRemover

Blocks in nearby source blocks.

## Settings

- **Priority** (Enum): `Furthest`, `Lowest`.
- **Range**, **Delay**.
- **Rotate** (Category): `Speed`.
- **Raytrace**, **StrictDir**, **Swap**.
- **Water** (Category):
    - **BubbleColumns** — Remove bubble column source blocks.
- **Lava** — Remove lava source blocks.
- **Render** (Category): `Color`.

## Commands

- `sourceremover`
