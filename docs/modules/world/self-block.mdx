# SelfBlock

Glitches you inside of a block.

## Settings

- **InsideCheck** — Checks if you are already inside a block.
- **Rotate** — Rotate towards the block placement.
- **Center** — Center the player before placing.
- **Only** (Category):
    - **Obsidian**, **EnderChests**, **Skulls**.

## Commands

- `selfblock`
- `selfblock <setting> [value]`
