# HotbarReplenish

Automatically replenishes items in your hotbar.

## Settings

- **Mode** (Enum): `Whitelist`, `Blacklist`.
- **WhileIdle** — Only replenish items while you are not moving or performing actions.
- **Inventory** — Pull items from your inventory to refill the hotbar.
- **Offhand** — Replenish items in your offhand slot.
- **Threshold** — The stack size at which the module will trigger a replenish.
- **Delay** — The delay between replenishing items.

## Commands

- `hotbarreplenish`
- `hotbarreplenish <setting> [value]`
- `hotbarreplenish blacklist remove <item>`
- `hotbarreplenish blacklist clear`
- `hotbarreplenish blacklist add <item>`
- `hotbarreplenish blacklist list`
- `hotbarreplenish whitelist clear`
- `hotbarreplenish whitelist remove <item>`
- `hotbarreplenish whitelist add <item>`
- `hotbarreplenish whitelist list`
