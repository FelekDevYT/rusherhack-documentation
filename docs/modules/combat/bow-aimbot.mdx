# BowAimbot

Automatically aims your bow.

## Settings

- **Targets** (Category) — *Configure the entity types to target:*
    - **Players** (Sub-category):
        - **FriendProtect**, **PrioritizeEnemies** (EnemiesOnly), **IgnoreCreative**.
    - **Hostiles** — Target hostile mobs.
    - **Passives** (Sub-category):
        - **IgnoreTamed**, **IgnoreNamed**.
    - **Neutrals** — Target neutral mobs.
    - **Vehicles** — Target boats and minecarts.
- **Extrapolation** — *How many ticks in the future to extrapolate* target movement.

## Commands

- `bowaimbot`
- `bowaimbot <setting> [value]`
