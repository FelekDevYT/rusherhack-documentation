# Anchor

Stops your movement when you are over a hole.

## Settings

- **Height** — The maximum height at which the anchor will pull you down.
- **Center** (Category)
    - **Range** — Distance to the center of the hole.
    - **RayTrace** — Use raytracing to find the center.
    - **Speed** — The speed at which you are pulled to the center.
- **Descend** (Category)
    - **Speed** — The speed at which you are pulled down into the hole.
- **Doubles** — *Descend into double holes.*
- **AutoDisable** — Automatically disables the module after successfully anchoring.
- **PitchControl** — *Only descend while looking at set pitch.*
    - **Pitch** — The required pitch to activate descending.
- **Delay** — The delay before re-anchoring.

## Commands

- `anchor`
- `anchor <setting> [value]`
