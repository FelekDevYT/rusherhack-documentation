# Criticals

Always do critical hits.

## Settings

- **Mode** (Enum) — Method to achieve critical hits:
    - `Packet`, `Jump`, `Motion`, `Grim`, `Delay`
- **Strict** — Uses stricter checks to ensure critical hits on certain anticheats.
- **WhileSprinting** — *Allows criticals while sprinting.*

## Commands

- `criticals`
- `criticals <setting> [value]`
