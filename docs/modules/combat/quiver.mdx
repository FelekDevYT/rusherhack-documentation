# Quiver

Shoots yourself with positive potion effects.

## Settings

- **Self** (Category)
    - **Cooldown** — The delay between shooting arrows at yourself.
    - **WhileMoving** — Allow the module to function while you are moving.
    - **Automatic** — Automatically shoots arrows when positive effects run out.
    - **Macro** — Trigger shooting via a macro.
- **Others** — Allow shooting positive effect arrows at other players (friends).

## Commands

- `quiver`
- `quiver <setting> [value]`
