# LagDetector

Prints a message in chat/on screen when the server is lagging.

## Settings

- **Delay** — The time in seconds to wait before considering the server lagging.
- **Render** — *Draws text on your screen when the server is lagging.*
- **Notification** — Send a system notification when lag is detected.
- **Clientside** — Only display the lag message to you.

## Commands

- `lagdetector`
- `lagdetector <setting> [value]`
