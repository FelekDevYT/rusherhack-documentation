# RusherCrypt

Encrypt and Decrypt chat messages that users with Decrypt online can see.

## Settings

- **Encrypt** — Automatically encrypt outgoing messages.
- **Decrypt** — Automatically decrypt incoming messages from other RusherHack users.
- **ChatObfuscation** — Obfuscates the chat while typing or viewing encrypted messages.

## Commands

- `rushercrypt`
- `rushercrypt <setting> [value]`
