# Spammer

Spams chat.

## Settings

- **File** — *Choose which file to use for spammer.*
- **Mode** (Enum) — *Choose how messages are picked from the spammer file:*
    - `In Order`, `Random`
- **Whisper** (Category) — *Privately message players on the server rather than post in public chat:*
    - **Command** — The command used to whisper (e.g. /msg).
- **Delay** — The delay between messages.
- **RandomDelay** — Adds a random amount of time to the delay.

## Commands

- `spammer`
- `spammer <setting> [value]`
- `spammer reload`
