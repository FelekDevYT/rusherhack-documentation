# ChatAppend

Automatically adds text to your chat messages.

## Settings

- **Custom** (Category) — *Enable the ability to use custom text:*
    - **Text** — The custom text to append.
- **Random** — *Append a random number at the end of your message.*
- **Prefix** — Text to add before your message.
- **Suffix** — Text to add after your message.
- **Between** — Text to insert between messages.
- **Separator** — The character used to separate original text from appended text.

## Commands

- `chatappend`
- `chatappend <setting> [value]`
