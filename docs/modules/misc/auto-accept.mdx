# AutoAccept

Automatically accept tpa requests and duel requests.

## Settings

- **Deny** — Automatically deny requests from specific players.
- **Friends** — Automatically accept requests from friends.
- **TPA** — Automatically accept teleport requests.
- **Duels** — Automatically accept duel requests.

## Commands

- `autoaccept`
- `autoaccept <setting> [value]`
