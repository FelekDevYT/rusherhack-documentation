# AutoMount

Automatically mount entities.

## Settings

- **Targets** (Category) — Choose which entities to mount automatically:
    - **Horses**, **Donkeys**, **Llamas**, **Boats**, **Minecarts**, **Pigs**, **Beds**.
- **Range** — The maximum distance to reach for mounting.
- **Delay** — The delay between mounting attempts.
- **Tamed** — Only attempt to mount tamed entities.
- **Rotate** — Rotate towards the entity before mounting.

## Commands

- `automount`
- `automount <setting> [value]`
