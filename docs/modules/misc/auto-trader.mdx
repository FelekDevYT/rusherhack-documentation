# AutoTrader

Automatically trades with villagers.

## Settings

- **Mode** (Enum): `All`, `Whitelist`.
- **AutoOpen** (Category)
    - **Range** — Maximum distance to open trader.
    - **Rotate** — Rotate towards the villager.
- **AutoClose** — Automatically close the trading GUI.
- **Delay** — Delay between trades.
- **Debug** — Show debug info for trades.

## Commands

- `autotrader`
- `autotrader trades <add|remove|list|clear>`
