# HitboxIgnore

Ignore entity hitboxes when mining.

## Settings

- **PickaxeOnly** — Only ignore hitboxes when holding a pickaxe.
- **RightClickCompatibility** — Enable compatibility for right-click actions.
- **Entities** (Category) — Choose which hitboxes to ignore:
    - **Players**, **Crystals**, **Hostiles**, **Passives**, **Neutrals**, **Vehicles**.
- **Blocks** — Ignore specific block hitboxes.

## Commands

- `hitboxignore`
- `hitboxignore blocks <add|remove|list|clear> [block]`
