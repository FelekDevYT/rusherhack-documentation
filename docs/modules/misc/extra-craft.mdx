# ExtraCraft

Modifications to crafting.

## Settings

- **AutoCraft** (Category)
    - **Recipe** — Select the recipe to craft automatically.
- **FastCraft** — Speed up the crafting process.
- **Inventory** — Craft items using the player inventory.
- **Delay** — Delay between crafting actions.

## Commands

- `extracraft`
- `extracraft <setting> [value]`
- `extracraft get <recipe name>`
