# AutoEat

Automatically eat when you are hungry.

## Settings

- **Mode** (Enum): `Hunger`, `Health`, `Both`.
- **Hunger** — The hunger level at which to start eating.
- **Health** — The health level at which to start eating.
- **UntilFull** — *Keep eating until health or hunger is completely filled.*
- **Return** — *Return to last held item* after eating.
- **Milk** — Automatically drink milk to clear effects.
- **GoldenApples** (Category) — *Use golden apples to refill hunger:*
    - **Burning** — *Use enchanted golden apples for fire resistance* when on fire.
- **Chorus** — Use chorus fruit as a food source.
- **Poisonous** — Allow eating poisonous foods (like rotten flesh) if nothing else is available.

## Commands

- `autoeat`
- `autoeat <setting> [value]`
