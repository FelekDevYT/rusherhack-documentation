# ChorusControl

Know where chorus fruit will teleport you.

## Settings

- **Accept** — Automatically accept the teleportation.
- **Others** — Show teleport destinations for other players.
- **Box** — Render a box at the teleport destination.
- **Tracer** — Draw a line to the teleport destination.
- **Color** — Customize the color of the renders.

## Commands

- `choruscontrol`
- `choruscontrol <setting> [value]`
