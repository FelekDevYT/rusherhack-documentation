# MiddleClick

Actions for middle clicking.

## Settings

- **Friend** (Category)
    - **Notification** — Send a notification when adding a friend via middle-click.
- **Pearl** (Category)
    - **Delay** — Delay between throwing pearls with middle-click.
- **Firework** (Category)
    - **Delay** — Delay between using fireworks with middle-click.
- **EntityNBT** — Copy NBT data of the clicked entity.
- **BlockNBT** — Copy NBT data of the clicked block.
- **BlockHitDebug** — Show debug information for the hit block.

## Commands

- `middleclick`
- `middleclick <setting> [value]`
