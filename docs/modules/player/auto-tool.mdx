# AutoTool

Automatically switch to the best tool.

## Settings

- **Attacking** (Category)
    - **DisableShields** — *Use an axe to disable the targets shield.*
    - **RequireAura** — Only switch tools when KillAura is active.
- **Mining** (Category)
    - **Prefer** (Enum) — *Which enchant to prioritize for blocks benefit from both:*
        - `Silktouch`, `Fortune`
    - **DurabilityPriority** — *Always use the lowest durability tool.*
- **Return** — *Swap back to the previous item* after use.
- **Inventory** — *Pull tools out of the inventory* if they are not in the hotbar.
- **MinDurability** — Do not use tools with durability lower than this.
- **Delay** — The delay before switching tools.

## Commands

- `autotool`
- `autotool <setting> [value]`
