# AutoWither

Automatically spawn a wither.

## Settings

- **Delay** — Delay between placing blocks.
- **SilentSwap** — Swaps items without the client-side animation.
- **StrictDir** — Enforced direction checks.
- **Rotate** (Category)
    - **Speed** — Speed of rotation.

## Commands

- `autowither`
- `autowither <setting> [value]`
