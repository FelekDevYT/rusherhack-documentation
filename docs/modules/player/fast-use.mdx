# FastUse

Use items faster.

## Settings

- **Delay** — The delay between item uses.
- **EXP** (Category)
    - **Pitch** — Force a specific pitch when throwing bottles.
    - **Throw** — Automatically throw experience bottles.
    - **SilentThrow** — Throw without the arm-swing animation.

## Commands

- `fastuse`
- `fastuse <setting> [value]`
- `fastuse whitelist clear`
- `fastuse whitelist remove <item>`
- `fastuse whitelist add <item>`
- `fastuse whitelist list`
