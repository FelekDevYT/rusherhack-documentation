# TickShift

Queue up movements while standing still.

## Settings

- **Mode** (Enum):
    - `Normal`, `Timer`
- **Ticks** — The number of ticks to queue up.
- **AutoDisable** — Automatically disable the module after the queued ticks are used.
- **2b2t** — Optimization for the 2b2t server.

## Commands

- `tickshift`
- `tickshift <setting> [value]`
