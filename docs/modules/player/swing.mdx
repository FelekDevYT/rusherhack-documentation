# Swing

Modify swinging.

## Settings

- **Speed** — The speed of the swing animation.
- **NoSwing** (Category)
    - **ClientSide** — Disable swing animation only on your side.
    - **Strict** — Enforce no-swing packets strictly.
- **Offhand** — Swing with the offhand instead of the main hand.

## Commands

- `swing`
- `swing <setting> [value]`
