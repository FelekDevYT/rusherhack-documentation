# NoSlow

Removes item slow down.

## Settings

- **Mode** (Enum) — The bypass mode for anticheats:
    - `Grim`, `Ncp`, `Vanilla`
- **Items** — Prevents slowing down while using items (eating, drawing a bow, etc.).
- **Blocks** (Category) — Prevents slowing down when walking on specific blocks:
    - **Ice** — Maintain normal speed on ice.
    - **Webs** — Move at normal speed through cobwebs.
    - **SoulSand** — No slow down on soul sand.
    - **SlimeBlocks** — Maintain speed on slime blocks.
- **Sneak** — Removes the slow down effect while sneaking.

## Commands

- `noslow`
- `noslow <setting> [value]`
