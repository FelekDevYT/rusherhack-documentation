# NoFall

Stops fall damage on some servers.

## Settings

- **Mode** (Enum) — The bypass method for fall damage:
    - `Packet`, `Grim`, `Anti`, `Tp`, `Legit`
- **Distance** — The minimum fall distance before NoFall activates.

## Commands

- `nofall`
- `nofall <setting> [value]`
