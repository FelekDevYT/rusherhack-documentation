# InventoryMove

Move and look around while in an inventory screen.

## Settings

- **Mode** (Enum) — The bypass mode for different anticheats:
    - `New Grim`, `Ncp`, `Vanilla`
- **Look** (Category)
    - **Always** — Allows looking around at all times while in a screen.
    - **Speed** — Adjusts the rotation speed while a screen is open.
- **Screens** (Category) — Choose which screens to allow movement in:
    - **Containers** — Chests, shulkers, hoppers, etc.
    - **ClickGui** — The RusherHack main menu.
    - **HudEditor** — The HUD customization screen.
    - **EscapeMenu** — The standard Minecraft pause menu.
    - **Others** — Any other GUI screens not listed above.

## Commands

- `inventorymove`
- `inventorymove <setting> [value]`
