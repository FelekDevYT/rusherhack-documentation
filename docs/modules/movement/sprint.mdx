# Sprint

Automatically sprint.

## Settings

- **Water** — Allows the player to sprint while in water.
- **AutoJump** — Automatically jumps while sprinting.
- **Omnidirectional** — *Lets you sprint in all directions.*
    - **Strict** — *Bypass stricter anticheats.*

## Commands

- `sprint`
- `sprint <setting> [value]`
