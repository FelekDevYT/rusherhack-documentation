# Flight

Fly like a bird.

## Settings

- **Mode** (Enum) — The flight logic to use:
    - `Normal`, `Creative`
- **Speed** — The horizontal movement speed while flying.
- **VerticalSpeed** — The speed of moving up or down.
- **AntiKick** (Category)
    - **BobFix** — Prevents the view bobbing effect that can trigger some anti-cheats.
- **Acceleration** (Category)
    - **Speed** — How fast you reach the maximum flight speed.
    - **MaxSpeed** — The top speed allowed for acceleration.

## Commands

- `flight`
- `flight <setting> [value]`
