# ElytraTweaks

Quality of life improvements for elytra flying.

## Settings

- **FixRocketDesync** — Fixes the desync that occurs when using firework rockets.
- **NoBounce** — Prevents the player from bouncing off blocks while flying.
- **Burst** (Category)
    - **Delay** — The delay between burst speed applications.
    - **Speed** — The speed of the burst.
    - **MaxSpeed** — The maximum allowed burst speed.
- **GrimRocket** — Extend the lifespan of firework rockets on 2b2t.
- **OnGround** — Apply tweaks even when considered on the ground.
- **Inventory** — Allow tweaks to function while the inventory is open.

## Commands

- `elytratweaks`
- `elytratweaks <setting> [value]`
