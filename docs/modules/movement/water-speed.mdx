# WaterSpeed

Go faster in water.

## Settings

- **Lava** — Apply speed settings while in lava.
- **DepthStriderRequired** — Only activate if the player has Depth Strider enchantment.
- **Speed** — The horizontal speed multiplier.
- **Vertical** (Category)
    - **UpwardsMult** — Multiplier for moving upwards.
    - **DownwardsMult** — Multiplier for moving downwards.
- **LavaMultiplier** — Specific speed multiplier for lava movement.

## Commands

- `waterspeed`
- `waterspeed <setting> [value]`
