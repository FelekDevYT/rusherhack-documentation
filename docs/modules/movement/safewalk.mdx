# Safewalk

Prevents you from walking off the edge of blocks.

## Settings

- **Slabs** — Applies safewalk logic specifically to slabs.
- **Riding** — *Prevents the entity you are riding from walking off blocks.*
- **Sneak** (Category)
    - **2b2t** — Optimization for the 2b2t server anticheat.

## Commands

- `safewalk`
- `safewalk <setting> [value]`
