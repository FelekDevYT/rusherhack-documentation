# Hitmarkers

Call of Duty style hitmarkers when you damage an entity.

## Settings

- **Time** — *How long the hitmarker stays on screen.*
- **Scale** — *The size of the hitmarker.*
- **Targets** (Category) — *Configure which entities trigger hitmarkers:*
    - **Players** (Self), **Hostiles**, **Passives**, **Neutrals**, **Vehicles**, **EndCrystals**, **Items**, **Projectiles**, **Others**.

## Commands

- `hitmarkers`
- `hitmarkers <setting> [value]`
