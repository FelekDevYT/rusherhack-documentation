# NoRender

Prevents certain elements from being rendered to improve performance or visibility.

## Settings

- **Player** (Category) — `Overlays`, `Bobbing`, `Hurtcam`, `Blindness`, `TotemPop`.
- **UI** (Category) — `Background`, `Scoreboard`, `PotionOverlay`, `ToastNotifications`.
- **Entities** (Category)
    - **Armor**, **FallingBlocks**, **Items**, **RidingEntity**, **ArmorStands**, **Projectiles**, **XP**.
    - **ItemFrames** (Sub-category): `OccludeDistance`, `Entity`, `Item`, `MapDecorations`.
- **World** (Category)
    - **Weather**, **Fog**, **BeaconBeams**, **CaveCulling**.
    - **BlockEntityLimit** (Sub-category): `Limit`, `Range`.
- **Particles** (Category)
    - `Fireworks`, `Barriers`, `Explosions`, `BlockBreak`, `Eating`, `Criticals`, `PotionEffects`, `TotemPops`, `Sprinting`.

## Commands

- `norender`
- `norender <setting> [value]`
