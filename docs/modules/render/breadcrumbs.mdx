# BreadCrumbs

Draws a line behind you as you move.

## Settings

- **Active** — *Toggle the recording of breadcrumbs.*
- **Width** — *The width of the breadcrumb line.*
- **Limit** — *The maximum amount of points to keep in memory.*
- **Color** — *The color of the line.*

## Commands

- `breadcrumbs`
- `breadcrumbs <setting> [value]`
- `breadcrumbs load <name>`
- `breadcrumbs save [name]`
