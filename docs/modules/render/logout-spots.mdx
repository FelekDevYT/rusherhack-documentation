# LogoutSpots

Highlights where players have logged out of the server.

## Settings

- **Mode** (Enum) — *How to display the logout location:*
    - `Coords`, `Distance`, `None`
- **Message** — *The message to show when a player logs out.*
- **Render** (Category)
    - **Box** (Sub-category): `Color`, `LineWidth`.
    - **Text** (Sub-category): `Scale`, `Health`, `Time`, `CustomFont`, `Color`.
- **Delete** — *Clear all saved logout spots.*

## Commands

- `logoutspots`
- `logoutspots <setting> [value]`
