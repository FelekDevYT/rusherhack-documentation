# BlockOutline

Highlights the block you are currently looking at.

## Settings

- **Thickness** — *The thickness of the outline.*
- **Depth** — *Render the outline through walls.*
- **Fill** — *Fill the highlighted block with a color.*
- **Color** — *The color of the outline and fill.*

## Commands

- `blockoutline`
- `blockoutline <setting> [value]`
