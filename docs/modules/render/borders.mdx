# Borders

Shows chunk and region borders.

## Settings

- **YLevel** (Enum) — *The vertical position to render borders:*
    - `Void`, `Sky`, `Player`
- **Chunk** (Category) — *Current chunk border settings:*
    - **Color**, **Fill**, **Outline**.
- **MapArt** (Category) — *Current map art border settings:*
    - **Color**, **Fill**, **Outline**.
- **Region** (Category) — *Current region border settings:*
    - **Color**, **Fill**, **Outline**.
- **Axis** (Category) — *Axis lines settings:*
    - **Color**.
- **Beacon** (Category) — *Beacon effect border settings:*
    - **Color**, **Fill**, **Outline**.
- **SpawnerActivation** (Category) — *Spawner activation range border settings:*
    - **Color**, **Fill**, **Outline**.

## Commands

- `borders`
- `borders <setting> [value]`
